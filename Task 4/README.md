# Predicting Insurance Claim Amounts

## Objective
Estimate the medical insurance claim amount based on personal data.

## Dataset
- Source: Kaggle – Medical Cost Personal Datasets
- Columns: age, BMI, children, smoker, region, sex, and charges.
- Link: [Kaggle Dataset](https://www.kaggle.com/datasets/mirichoi0218/insurance)

## Steps Performed
- Cleaned and encoded categorical data (sex, smoker, region).  
- Performed EDA to understand relationships between BMI, age, smoking status, and charges.  
- Trained a Linear Regression model to predict insurance charges.  
- Evaluated performance using MAE and RMSE.

## How to Run
1. Open the notebook in Google Colab.  
2. Upload `insurance.csv` when prompted.  
3. Run all cells to reproduce the results.
